`上海正式软件类`

**职位描述**

1. 参与三维重建软件与扫描设备的测试工作,负责功能测试、回归测试、兼容性与稳定性测试。
2. 设计并执行重建质量评估:围绕重建精度、完整度、纹理/渲染效果、位姿精度等制定量化指标与评测方法。
3. 参与真机数据采集与测试用例设计,构建覆盖多场景(室内/室外、不同光照、不同物体)的测试数据集。
4. 定位并跟踪缺陷,复现问题、提供清晰的日志与数据,与算法/研发团队协作推动修复与验证。
5. 参与测试流程与工具的建设,推动测试自动化与效率提升。

**职位要求**

1. 2026 / 2027 届本科及以上学历,计算机、软件工程、自动化、电子信息、测绘、数学等相关专业。
2. 具备基本编程能力,掌握 Python 或 C++ 至少一门,能编写测试脚本处理数据。
3. 理解软件测试基本理论(测试用例设计、缺陷管理、测试流程),做事严谨、注重细节。
4. 良好的问题分析与复现能力、沟通能力与责任心。
5. 对三维视觉 / 点云 / 三维重建方向有兴趣并愿意深入学习。

加分项：

1. 了解三维视觉基础概念(点云、相机成像模型、多视图几何、SfM/SLAM、NeRF/3DGS)。
2. 用过点云/三维处理或可视化工具:CloudCompare、Open3D、PCL、MeshLab、Blender 等。
