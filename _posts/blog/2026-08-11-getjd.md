## 禾赛（PlayWright）

主要使用 PlayWright 抓取岗位信息。

**1、生成抓取程序**

输入要求给 DeepSeek，请 DeepSeek 生成抓取程序。

```md
1、禾赛科技的27届校招岗位列表：https://kwh0jtf778.jobs.feishu.cn/229043/position/list
2、预计有约150个岗位，分15页呈现，每页不超过10个岗位
3、抓取岗位详细信息。每个岗位详细信息，可参考：https://kwh0jtf778.jobs.feishu.cn/229043/position/7662646357531166982/detail

请输出程序，用playwright

===

1、多输出些调试信息。比如岗位名称，岗位职责有几个字，岗位要求有几个字
2、每抓取到了一个岗位，先写入文件保存。再抓取到了一个岗位，追加保存到文件中
3、加快抓取速度。当前抓取一个岗位详情页，太慢了。
```

多次调试后，得到可运行的程序：[hesai.py↗](getjd.assets/hesai.py)

抓取到的信息，保存在 json 文件中：[hesai_jobs_2026.json↗](./getjd.assets/hesai_jobs_2026.json)

**2、将json转换为md文档**

经相关要求告知 ds，可生成转换文档。此处从略

```md
1、岗位标题，用2级标题，取值是 title

2、接下来是 location job_type category，格式： `location` \| `job_type` \| `category`。比如 `上海` \| `式` \| `光学类`

3、增加文字“职位描述”，加粗显示。换行后显示  description

- description 中的 1 2 3 等，改成 有序列表

4、增加文字“职位要求”，加粗显示。换行后显示  requirements

- requirements 中的 1 2 3 等，改成 有序列表

5、最后显示 “官网投递↗”，链接取值是 url
```

**3、手工浏览**

将上述岗位 md 文档，复制粘贴到本站的帖子的 md 文档中。再手工检查格式，或注释掉不收录的岗位，就可以发布了。
